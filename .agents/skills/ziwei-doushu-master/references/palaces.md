# 十二宫、宫与位、六条线、身宫

批具体宫位、六亲、或要用「位」作第二层时读本文件。

## 宫和位

宫是绝对称呼：你的父母宫就是你爸妈那一格。  
位是相对称呼：你的爷爷，既是你的福德宫，也是你父母宫的父母位。

先按本宫本义批，再按「位」作第二层。禁止一上来套三层，会晕。

常用第二层（点到即可）：

- 看母，常看兄弟宫（父母宫的夫妻位）
- 流动资金，有人看兄弟宫（财帛宫的田宅位）
- 工作伙伴，可看子女宫（官禄宫的仆役位）

## 十二宫（本命＝态度，不是吉凶判决）

**命宫**：本质、第一人格。别人第一眼常常先碰到的是迁移宫，不是命宫。

**兄弟宫**：和兄弟姐妹的相处；兼看与母亲的模式。

**夫妻宫**：择偶观和对感情的态度。不是桃花宫。合盘时对比双方命宫与夫妻宫。

**子女宫**：子女；桃花常落在这里；也是合作伙伴、官禄的仆役位。

**财帛宫**：理财态度、物质欲望、吃资源程度。财帛突出＝比较吃资源，会花钱也更敏感赚钱机会。不直接等于有钱。

**疾厄宫**：身体态度和物理层面的负担、作息、极限消耗。不是软件上的「健康宫＝没病」。口播只谈倾向，不诊断。身体不舒服要就医。

**迁移宫**：对外包装、人设、路人缘。迁移特别好，会立人设；特别差，可能不修边幅或不善交际。相处久了会透过迁移看到命宫甚至福德。

**仆役宫（交友宫）**：圈子、择友观、沟通。很少有人主动问，但兄友线一动就重要。

**官禄宫（事业宫）**：处事态度。学生的学习、全职照顾家庭、没有上班，都算日常工作，照样要看。

**田宅宫**：收藏、不动产、家人关系、财库。财帛旺田宅破，会赚也会花；财帛弱田宅旺，会存。

**福德宫**：经过思考的内心、欲望、休息、容错率。师傅说修福德，就是把心跳稳。其他宫很多是潜意识，福德是想过再做。

**父母宫**：唯一先于命宫、不能选的宫。多数时候看父亲与先天养分。父母宫过于突出，离开庇佑后挑战更大。盘要平衡。

## 隐藏宫

**身宫**：后天加点方向，中年后愈发明显。只落六宫。

| 身宫落 | 人话 |
|---|---|
| 命宫 | 方向很定，不撞南墙不回头。方向对就稳，方向错也难劝。 |
| 迁移 | 在意外人眼光和外在表现，求认可，爱往外跑。 |
| 夫妻 | 重感情，容易为情所困，也可能伤够了就远离。 |
| 官禄 | 在意做事方式，容易工作狂；方向不对打击也更大。 |
| 财帛 | 物质安全感特别重，君子爱财要取之有道。 |
| 福德 | 重精神享受，成瘾性更高，方向走错最棘手，要管心理。 |

**暗合宫**：盘面左右镜像，地支六合。台面下的属性。明科暗禄：命宫化科，暗合宫有化禄或禄存。

**来因宫**：年干所在宫，看「为何而来」，行业参考，用得少。子丑不做来因（天地不做来因），改找寅卯（宫干相同）。

## 地支三类（给人加成，不是吉凶）

- **四生地 / 四马地**（寅申巳亥）：行动力、探索欲，也善变。天马只落这里。
- **四旺地 / 四败地**（子午卯酉）：自信、控制欲，也冲动，容易做超出能力的事。
- **四墓库**（辰戌丑未）：稳重专注，活力冲劲低一些。禄存遇土不进。

## 六条对冲线

互冲的两宫互相关照，也有矛盾。熟记别称，解盘能少绕路。

| 线 | 宫 | 人话 |
|---|---|---|
| 命迁 | 命、迁移 | 表里 |
| 兄友 | 兄弟、仆役 | 沟通、圈子、成就 |
| 官夫 | 官禄、夫妻 | 事业与配偶互相牵制 |
| 子田 | 子女、田宅 | 桃花、亲子、合伙、家庭 |
| 财福 | 财帛、福德 | 消费观、精神满不满足 |
| 父疾 | 父母、疾厄 | 文书、契约 |

例：夫妻宫化忌冲兄友线 → 先想感情里的沟通问题。

## 三方四正

本宫 + 对宫（六冲、四正位）+ 两个三合宫（三方位）。

命宫的三方四正固定是：命宫、财帛、官禄、迁移。

财运不要只看财帛，要连带命、官、田宅或福德。感情看夫妻及其三方（常牵官禄、福德、迁移）。事业看官禄，兼看官夫线。

空宫：借对宫星系，更受三方四正和暗合影响。空宫不是没格局，是主心骨在外面，海纳百川也容易迷茫。
