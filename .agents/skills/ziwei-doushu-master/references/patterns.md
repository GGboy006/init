# 格局词典

定完三方四正后扫描。成格才点，破了就说破。一轮最多 1～3 个，跟当前问题有关。先人话后格名。不念贫贱凶，不打包票。

格局是套装属性。不知道格名也能解盘。古书条件常有分歧，有分歧就说「资料有两种算法」，不要装成只有一种。

机月同梁、杀破狼很常见，降调。君臣庆会那种条件严的，可以多半句分量，仍落到今天的策略。

## 点法

成格四关：星在哪、宫对不对、三方有没有冲破、本命有还是运限才亮。

- 成格：人话本质 + 格名 + 今天怎么用
- 破格：点名「格破了」+ 按破格后的性格讲
- 运限点亮：本命有底，这十年这套被打开

## 优先点的格

### 君臣庆会

条件严，命宫三方四正不宜有煞忌。常见说法包括：紫微破军命宫且辅弼夹；紫微天相在命迁上见昌曲；天府命宫被机月同梁夹。古书另有「紫微左右同守命」就算，和夹宫派有分歧。

人话：得道多助，像能被看见、被提拔的管理层胚子。有规划、能发现问题。  
破格：三方有煞忌，别念材善经邦。

### 紫府同宫

紫微天府只在寅申同宫。  
人话：无法接受平凡，有章法，也容易眼高手低、为面子买单。人格魅力随阅历长。不要说躺着福厚。

### 紫府夹命

命宫天机太阴，紫府夹着。常叠机月同梁。寅申才成。  
人话：成长环境、靠山、提携。个性极度避险，适合体制深耕；没进体制的要逼自己求变。

### 极向离明

紫微在午，三方无煞。  
人话：规划和管理能打出来，午宫紫微本身就偏霸道。无煞才是总裁，有煞就只剩霸道。格破了按后一句讲。

### 极居卯酉

紫微贪狼在卯或酉。见紫贪双星。  
人话：好奇、探深层意义；玩够了看破，或求而不得就逃避。不是僧道宿命。

### 机月同梁

命宫三方四正凑齐天机、太阴、天同、天梁。条件松，很多人有。寅申同梁或机阴，含空宫借对宫。  
人话：风险厌恶，被动星多，求稳、不爱换赛道。无煞忌时深耕会稳步升；有煞忌时对机会容易误判，进错行会很纠结。不要说下格没出息。

### 善荫朝纲

天机天梁同宫。  
人话：脑快嘴快，仁慈家长，适合企划幕僚，协调多方。不甘拧螺丝，也不爱当领头羊，活在中层最顺。

### 府相朝垣

天府在官禄、天相在财帛来会命。条件宽，常是别的格的挂件。  
人话：辅助技能，四平八稳、食禄的底。命在寅申更有话说。不是自动千钟俸。

### 杀破狼

命宫见七杀、破军、贪狼任一（三方必会齐）。占比高。  
人话：求新、不服管、能破釜沉舟，守成比开创难。古书宜出外，是坐不住。不要吓大起大落、夭折。  
变体：七杀在子午寅申为七杀朝斗/仰斗，更硬气，能力配不上就变成空炮。破军子午为英星入庙，开创上限高，也要经过磨。

### 武贪同行

武曲贪狼在丑未同宫。  
人话：先天条件很好，刚愎是坑。少年太顺容易目中无人；磨过才厚积薄发。不要吹上天或贬下地狱。

### 火贪 / 铃贪

贪狼会火星或铃星，庙旺更显。  
人话：搏性、横发横破。古书其实更论官，不只是一夜暴富。用事业带财比梭哈稳。铃贪是后人说的，一样按爆发和反复讲。

### 巨日同宫 / 日照雷门 / 日月并明反背

巨门太阳同宫：口舌见光，说理、争议、名气一体。  
日照雷门：太阳天梁在卯。  
日月并明 / 反背：看日月是否同亮或一背。  
人话落到表达、公开场、口碑，不落到科举。

### 月朗天门 / 明珠出海

太阴在亥（天门）守命或身。明珠出海是太阴出低位转亮的象。  
人话：夜间的富和细，在对的位置会发光。

### 刑囚夹印

天刑或擎羊（刑）+ 廉贞（囚）+ 天相（印）。变体还有夹忌。  
人话：规矩、合同、对错被放大。法律审计风控会忙；打擦边球不保护你。不是牢狱套餐。运限遇到，老板先清税务人事合同。

### 三奇加会

命宫三方四正集齐化禄、化权、化科。后人归纳。命科、财禄、官权最讨喜。  
人话：机会比别人略多一截，抓不抓得住看本人。结合所附之星讲，不要空喊三奇。

### 禄马交驰

禄存天马同宫（全书口径；有人放宽到三方）。只能在四马地同宫。  
人话：本钱在流动，忙、机会多。见杀羊火空亡就变劳苦奔波。禄马佩印是再加天相，财上加权，仍要人接得住。

### 禄合鸳鸯 / 明禄暗禄 / 两重华盖

化禄与禄存同宫或对拱：本钱变多。  
明禄暗禄：本宫一禄，暗合宫另一禄。  
两重华盖：禄存化禄再遇空劫——钱过袖，别把人生目标只盯在钱上。同一张盘里格与格会打架，当系数，不当判决。

### 左右同宫 / 左右夹命 / 辅弼拱主

左右同宫：辅弼同守命或身，能组织也能把关系做顺。  
左右夹命：辅弼紧邻命宫两侧，像两边有人帮，不是三方会照。  
辅弼拱主：紫微守命，辅弼拱或夹。有意愿做主，也容易形成班子。紫微被煞破，或只想控不愿分工，好处会薄。

### 魁钺夹命 / 坐贵向贵

魁钺夹：魁钺紧邻命宫两侧。  
坐贵向贵：一坐命、一向迁。  
人话：贵人不是代做，是容易碰到要求高、能提点的人。自己有货才留得住。

### 羊陀夹命

羊陀分居命宫前后，被夹的命宫必有禄存。不是三方见羊陀。  
人话：能守、抗压、对风险敏感；再被忌空劫牵，就变成反复受阻、因固执吃亏。重要决定留余地，别赌气硬扛。

### 劫空夹命

地劫地空分居命宫前后。  
人话：计划落空、落差感。本命有是长期课题，限运临是阶段性。古人断得很重，今天改成：资金承诺合作要验证、留后手。主星稳健也可能变成危机意识。

### 昌曲相关

文昌文曲同宫（文贵文华）：条理加感受，学习表达审美。  
昌曲夹命 / 文星朝命：文书、考试、作品被看见。落到兴趣领域，不要断言学霸。

## 少点或降调的格

- **金舆扶驾**：按「紫微前后日月夹」安星上几乎不成立。有资料改成帝星被日月夹。不确定就不要叫这格。
- **生不逢时、铃昌陀武投河**：古书吓人。按星性讲空忙、怀才不遇、别钻牛角，禁止念夭折投河。
- **梁马飘荡**：天梁天马，好动侠气，古书骂女命的句子一律不用。
- **网上自创、宫位不对、只是两星同宫硬安大名字**：跳过。

## 口播禁用

「帝王命」「下格」「男盗女娼」「必有官非」「一生富贵」。改成性格系数、适用策略、这十年怎么用。
