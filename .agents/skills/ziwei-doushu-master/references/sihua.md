# 四化与飞星

讲课题、对待关系、应期流向时读本文件。默认全书南派四化表。对方盘若是另一派，先对表。

## 总原则

星曜组合是环境，四化是念头。四化不能独立存在，只依附星曜，改它的活性。先用三合看象，再用四化看数。没有格局当比例尺，不要第一步就抓化忌。

运限四化：本命、大限、流年（以及月日时）。本命和大限因人而异；同一年的流年四化大家相同，落宫不同所以感受不同。  
宫位四化：每宫宫干飞出禄权科忌，看宫与宫怎么对待。

## 生年四化：内心感受

站在命主自己的感受上讲，外人未必同感。

**化禄**：增加、当下开心。增的是该星本质，所以破军化禄是增加消耗，天同化禄是更享福也可能更不进取。与生俱来的好，自己常感觉不到。星曜组合不好时，化禄也可能是心甘情愿付出却得不到正面反馈。

**化权**：掌控、责任、执行。官禄有权，想把工作抓在手里。不自动等于升职，但手上的事会变多。落六亲宫像权力转移，想管就容易争。

**化科**：面子、贵人、舒适、广而告之。身心累了来回血的宫。不想让人知道的事化科，对本人不算爽。六亲化科，那宫的人较有涵养；六事化科，不太费力就舒服，也难出舒适圈。想做大事业，过平顺不一定够。

**化忌**：执念、在乎、觉得缺。感受最强的一化。不是灾星，是肚子饿才会去找吃的。落六亲：那关系一分歧，内心伤害大。落六事：觉得这宫有缺，例如财帛忌的人常觉得钱少，反而可能闷声发力。

口播对照：禄＝获得感；权＝想做主；科＝有面子；忌＝特别在乎、较劲。

## 叠化（同宫多种四化）

特质不会消失，会拧在一起，让人更盯着这宫。

- 禄忌：开心的来源却觉得不够，食之无味弃之可惜。像中奖了兑奖券丢了。
- 禄权：开心且想掌控，控制欲强，想在这宫出成绩。
- 禄科：开心又有面子，爱展现，较自信。
- 权忌：想掌控又觉得不够，要求过高，易矛盾。
- 权科：想掌控又要名声。
- 科忌：该有面子却有不足，变成默默付出。

## 飞星句法

A 宫的宫干让 B 宫某星四化，叫 A 飞某化入 B。若 B 化忌，还会冲 B 的对宫 C。

一律透过命主看。大众觉得好的，对本人可能是烦恼。解伴侣误会有用，也有造成新误解的风险，慎用。

- **A 化禄入 B**：A 喜欢 / 满意 B，B 是 A 的快乐来源，A 让 B 的能量增加。
- **A 化权入 B**：六亲则依赖、托付、希望对方多担责；六事则 A 想掌控 B，自己也要为 B 多做。
- **A 化科入 B**：B 是 A 的面子和贵人，A 爱展示 B，觉得 B 能帮忙解忧。
- **A 化忌入 B**：A 牵挂 B，觉得 B 是烦恼来源。忌冲到对宫 C 时，作者口径认为真正让 A 烦的常在 C，冲有分开、抽离的意思。
- **自化**：自我感觉，不一定客观，较难靠外界纠正。自化禄：觉得够了，不太珍惜。自化权：自我加压要负责。自化科：近自恋、自我感觉良好。自化忌：自寻烦恼。

口播飞星：少说「甲干飞忌入夫妻」。改成「你工作这宫，飞到感情上是较劲的，像把职场那股较劲带回家」这类人话，再补一句宫名方便以后查。

## 和时间层叠在一起

生年有禄、大限再加禄：双禄，资源加倍。  
生年有禄、大限来忌：忌破禄，先天资源受阻。  
大限弱、流年化禄：短机会，要控规模。  
大限强、流年化忌：有底，但今年这宫费心。

先定大限主题，再看流年触发，最后看两者同向还是拉扯。
