# 主星、双星、辅煞、亮度

定命宫主人翁、讲性格时读本文件。口播用人话，必要时补星名。

## 怎么用星

主星给宫位定调，像老师定一个班的底色。辅星是班委，空宫里辅星会被放大。杂耀是加减分。神煞更像气质附魔，不熟可以略过。

吉星煞星不当绝对好坏。吉星更会交际、面善；煞星更不走寻常路、不太合群。人不可貌相，星也一样。

双星不是两星相加，是融出新气质。例如武曲刚直，碰上贪狼，棱角会被磨圆，欲望会更务实。

星曜特质是本能趋势，认知和教育会修。任何一颗星都有好人，切勿戴有色眼镜。古籍骂词（至淫、不忠不孝）要放回时代，改写成今天的性格。

## 亮度

亮度是「表现这颗星的欲望」强弱。庙旺主动外放，落陷内收、犹豫。七杀庙旺果决，落陷锐气受阻。落陷的太阳像太阴，庙旺的太阴似太阳。

口播不要念庙旺表，只说「这颗星在这位置很亮，个性会往外顶」或「落得暗，同样的性格会往心里收」。

常用四级：庙、旺、利、陷。有的门派用七级（庙旺得利平不陷）。亮度表门派有出入，以盘图标注为准。

## 常见双星（命宫见到就用）

**紫微天府**：双帝，控制欲和面子都重，虚荣和务实打架，难果断。福德必贪狼，爱好广。要匹配能力，别当韭菜。

**紫微七杀**：紫微被拉接地气，更坚定。适合深耕专业；摆烂也难劝。防 PUA。

**紫微破军**：魄力大、叛逆、熟了窝里横。面子撑得辛苦，圈子影响大。

**紫微贪狼（桃花犯主 / 极居卯酉）**：社交、好奇、难专精。古书「至淫」是误会。占有欲重，禁不起激，别吹捧自己上坑。

**紫微天相**：古书「不忠不孝」是不服管。平衡、敢把想法做出来，前途挂在伯乐上。

**天机天梁（善荫朝纲）**：脑快嘴快，大家长，适合幕僚企划，怕当一把手，怕寂寞，嫌笨蛋。

**天机太阴（机月同梁的核心之一）**：求稳、风险厌恶，熟悉环境里能深耕。

**天机巨门**：话和观察叠在一起，贵也破荡，古书极端，按表达欲和机心讲，不按公卿或淫佚讲。

**武曲贪狼（武贪同行）**：能干、好学、敢做，致命是刚愎。武贪不发少年人：太顺易目中无人，要磨过才厚积薄发。

**廉贞天相**：印被囚，情商使不出；再加刑羊，冲动容易惹规矩。见刑囚夹印。

**杀破狼**：七杀、破军、贪狼三方会见。命宫任一颗都算。占比高，降调讲。不服管、求新、能破釜沉舟，守成比开创难。宜出外是因为坐不住，不是命里必须流浪。

**太阳天梁 / 巨日**：公开场、口碑、说理。日照雷门是太阳天梁在卯。

讲双星时：先融合气质，再提醒这组的坑，最后落到对方问的那一宫。

## 十四辅星

六吉：左辅、右弼、文昌、文曲、天魁、天钺。助力、文书、贵人。  
六煞：擎羊、陀罗、火星、铃星、地空、地劫。压力、阻、爆、空。  
二助：禄存（本钱）、天马（流动）。

顺序：主星 → 庙旺 → 四化 → 辅佐 → 煞曜。煞忌先入眼，最容易把整张盘看成灾难。

禄存在四墓库不进。羊陀永远夹禄存：夹命时命宫必有禄存。

## 杂耀与神煞

杂耀归类记，不颗颗背。神煞分长生十二神、博士十二神、将前、岁前。解盘不熟就略。口播不要报一串小星充专业。
