# 实盘归档

解盘的价值在复盘。攒的是「哪条断法被实事核过」，不是攒漂亮话。

**这里只存档，不借鉴。** `cases/` 是本馆自己的账：盘面、顾客原话、对上没对上、卡点。新盘不许引旧案例、不许拿旧盘的断语套新盘——学案例是倪师智能体那边的事（天纪那二十几个实盘在它库里），这边的案例只用来跟自己的断法对账。验证账也只管本馆的账，不升格成判准；判准永远在 `zhuqi-zwds` 和 `knowledge/iztro/`。

## 三样分开

批法规则进 `SKILL.md`。这一盘的果进 `cases/`。跨盘反复应验的断法进 `cases/验证账.md`。当次批词一律不进 `SKILL.md`。

发现的毛病进 `.cursor/skills/zhuqi-zwds/PENDING.md`，攒一批再合。归档时不要顺手改 `SKILL.md`。

## 写之前

从对话里捞，不重批、不补断、不美化。顾客没说过的验证不许编。当次没验的写「待验」，别凑。

匿名：不写姓名、生日、住址、联系方式。年龄写段（二十岁上下、四十来岁）。

文件名 `cases/日期-性别局数-命宫主星.md`。命宫空的写「空借某某」。

## 案例模板

九栏，缺的写「无」，不留空标题。

**档位**：走到哪一步（专项答 / 全盘批本命段 / 全盘批大限流年段 / 精批），实际用了多长时间（专项约 30 分钟、全盘 60–90 分钟是参考，记实数），中间升过档、改过分支没有（客人坐下说事，中途改成全盘都看看，这类要记）。这一栏决定后面几栏该有多厚——专项答口语可以薄，底气仍要厚；只到本命段的案例本来就薄，不是漏记。

**气口**（选填，不保证每次记就空着写「无」）：这次重断用的气口 1（重话版）还是 2（善说版）；客人当场反应——点头、反驳、吓到、松口气，挑一个或写原话；你自己说顺了还是说别扭。攒十盘八盘回看，哪个气口是你的就出来了。

**定盘**：过、还是带着「不牢」放行的。核过哪几条锚点、哪一条是带年份那一层、有没有换盘比对。标了不牢的写清是哪一条，以及后面哪几个断跟着打了折。**定盘没过就不该有这份案例**，有就说明流程被跳了，记下来。

**盘面**：输入是 JSON 还是图，软件是哪个。阴阳男女、局、命宫、身宫、财官迁、关键四化落宫、点过的格与短板。亮度记到七级里的哪一级，不折成四级。只抄盘上有的。

**来人**：年龄段、身份、开口问的是什么。开场三问收来的现状（上班还是自己做、什么行业、合伙没有、求稳还是求闯）和他带来的两三个具体问题原样记下——问法本身就是材料。

**断了什么**：一条一句，可核，带上指回的宫和星。抄【你的底气】那一层，不抄口语的场面话。精批的飞化要把推导抄全：哪一宫的宫干、四化是哪四颗、分别飞进哪宫；只抄结论的等于没记，以后没法复核。

**顾客怎么应**：原话尽量留。分对上、没对上、待验三种，别都算对上。没对上的必须写，写清是宫认错、星看错、宫干起错、亮度折错，还是断法本身不成立。

**卡点**：哪句听不懂、要求几次白话、哪个问法被打回、哪一句被他当场反驳。这一栏最值钱，下次批法照它改。听着像上课、遮星测试本该拦下却漏出去的句子，也记这里。

**回头看**：这次哪条断法有效、哪条该写进 `PENDING.md`、哪条该上验证账。

## 底稿末尾两行

精批档出过书面底稿的，底稿末尾那两行照抄进案例，不要重写：

**待验**：哪几条带年份、等哪一年对账。没有年份的断进不了这一栏——性格和倾向永远说得通，也永远证不伪，攒不出手艺。

**不牢**：定盘哪个锚点不实、哪几条断跟着打折。

## 写完

顺手更新 `cases/验证账.md`：

新条目进「待观察」。**上待观察要带年份或可核的事实**，「他性格急」这种进不去；「2019 年换过方向，对上大限换宫」才进得去。

已在待观察里、这次又被核上的，转正并记次数。

被实事推翻的，挪进「落空过的」，写清怎么落空——是断法不成立，还是这次盘认错了。分不清就写分不清，别替自己开脱。

## 禁止

编造验证。把「顾客没反驳」当对上。把待验写成对上。

存口语全文。存能认出人的信息。

归档时给新断语、接着批命、顺手改 `SKILL.md`。

定盘没过的盘也归档成正常案例，不标出来。

在本仓库创建非 md 文件。
