# 解盘发帖

看盘涨粉慢，因为完整看盘是成交内容，不是发现内容。滑动的人停在一句错见、一个场面，不停在整场交付。

实盘帖从这盘里抽一刀。不搬整盘。

**默认只写公众号。** 公众号效果更好；小红书官方可用公众号链接直接取文发布，所以不必再单独写小红书。用户没点名小红书，就只交【公众号】一块。只有用户明确说「还要小红书 / 两版都要」时，才加小红书。

**连发实盘、只推命、只吓人，容易把读者摁进「我命不好」，也容易被平台当成迷信恐吓。** 所以账号里要掺科普：挑一段讲清斗数在讲什么。科普不是整本教材搬家，是挑着发；姿态可以落在讲清楚一门老学问、弘扬传统文化上，不当算命恐吓帖。

**两套口气，不要混。**

实盘三类（拆一条 / 看盘故事 / 匿名实盘）跟解盘同一路，但有两处有意不同：一是**星名讲全，不许简称**；二是**必须有意思**——场面准到读者说「这是我」。平辈、短句、能拍，不摆长者架子。

科普一条**不是**坐馆批盘，也**不是**实盘那种对话感。写法要参考用户丢来的那份手打科普（例如指定网站某一节）：有思考痕迹、段落把理说完、例子跟着论点走，读起来像人写的说明文，不像模型一股脑生成的金句串。禁止把「说白了 / 这种盘 / 先搁着 / 演出来」那套坐馆口语腔搬进科普。

## 写之前

**实盘三类**：材料从对话或 `cases/` 里捞，不重批、不补断、不美化。顾客没说过的验证不许编。待验就当没验。

**先天底子还没批到大限流年、场面的，抽不出实盘帖。** 实盘帖全靠场面停住滑动。要抽实盘帖就从后续追加（大限流年、专项答疑）或精批档的料里抽；手上只有先天底子那一段的，说清楚，让人把后面的交付内容或案例丢进来。

**科普一条**：不要求有盘。材料必须是用户指定的链接里某一节、或用户贴出的原文段落。写之前先读原文，论点、层次、例子都贴着原文走；可以换词、压缩、顺平台篇幅，**不许臆想发挥、不许另起炉灶讲原文没有的断语或案例**。整页教材、整站目录一律不搬；只挑用户点名的那一截。外站原文禁止整段粘贴；用自己的句子重述同一套理，保留原文的思考顺序和具体例子（时辰交界、医生记录误差、夏令时、因材施教等——原文有的才写）。

用户指定帖型就按指定。没指定时自己选：十帖里实盘最多两三帖；连发实盘或语气偏「命不好」时，优先改抽「拆一条」「故事」或「科普一条」。段首用一行报刀（实盘如「抽迁移那条」；科普如「科普：依据××节·能干嘛」），然后直接写公众号，不问要不要继续、不问要不要小红书。

选刀优先级（实盘）：顾客原话对上的 ＞ 卡点最狠的 ＞ 打错见最利的。

紫微、流年、阳宅的实盘都走这一份。实盘三类没有盘的材料：不编盘、不编客人，让人把对话或案例丢进来。科普一条没有指定段落：不写，让人把链接或原文丢进来。

## 四种帖型

**拆一条**（涨粉主力）
打掉一句俗见。这一断必须指得回这张盘的星或宅，但帖里不讲这个人的命。结构：俗见一句 → 当场打掉 → 换成能拍的场面 → 收在活法上。星名点一颗就够。

**看盘故事**
一个场面、一句断语。有验证才写下半句怎么应；没有就停在场面，不许把待验写成应验。不写来人身份清单。

**匿名实盘**（证明手艺，十帖里最多两三）
来人问什么 → 断了哪一句 → 怎么应。只留这一刀需要的那颗星、那个宫。局数、全宫清单、四化报菜名不进帖。原话改写到本人也对不上号，不断义。

**科普一条**（养号、减压、文化向）
按指定原文的层次讲清。不排具体命、不点某个客人、不恐吓「你命不好」、不编坐馆案例。结构跟原文走（原文先讲能干嘛再讲原因，就不要先改成打错见故事）。小标题可以保留原文类目（性格推演、子女教育等），读者要对得上那是一篇说明，不是批盘。星名、术语以原文出现的为限，不堆课。同一主题下次换另一截；禁止把整章术语表、干支表、时辰表灌进一篇。

## 篇幅与写法（公众号）

先写可粘贴的正文，再给标题和摘要。不要先交差策划案。

**实盘**：把这一刀的依据讲清。正文 800～1400 字，超过 1800 砍。可以点宫、点亮度、点「换这颗星会断成什么」。亮度按七级说，不得地不等于陷。开头两行必须是错见或场面，不能是「今天给大家看一盘」。仍是给一个人讲，不是上课。星名最多点到把理说清为止，不要报菜名。

**科普**：按原文把这一节说完整，800～1400 字，超过 1800 砍。可以保留原文的分点（出生时间错误、水平、表达等），表格可改成短述。开头用原文的问题或第一句理，不要坐馆开场，也不要「今天科普」。读感要像手写说明文：段落把一个理说完再换下一个，禁止金句排比、禁止每段都「不是甲是乙」。

小标题用单独一行中文，不用 `#`。

**仅当用户明确要小红书时**：另开【小红书】块。实盘：开头错见或场面，正文 350～600 字，超过 800 砍，星名最多两颗，三个标题 + 封面一行 + 话题 3～5 个。科普：按原文缩层次，例子留两三个，删表，同样字数与标题封面。禁止把公众号正文复制缩短充数——若两版都要，各自成篇。小红书正文纯文本，不用 markdown。

## 口气（实盘三类）

平辈讲话，有判断、有褒贬、短句、场面能拍。不摆长者架子，不用「你记住」压人。

读者是滑动的人，不是坐对面的顾客，所以用「这种盘」「这种人」，少用「你」钉死读者的命。

**先人话，后点星。** 开头两行是场面或错见，星名跟在后面当锚。一上来就报星名，人已经划走了。

语气词（啊、嘛、吧、就是、说白了）可以有一点，疏密像说话，但公众号比口头批盘少用。语气词不许让判断变软，也不许刷成宝子腔。

压缩断不许单独成句。按判据查，不照词表查：一句话十来个字、通篇判词没有场面（路在某宫、贴着某星、撑不住、漏、管道在外面）；拿名词化的比喻当主语（那座库、那条线、这口气、那笔、场）；「不是甲是乙」两头都虚。三样都算，全部改成谁、在哪、干什么。

星名讲全，不许简称（紫杀、机月同梁、日月、羊陀、昌曲、空劫）。只有排盘的人才懂的缩写，一律换成人话。

句子长短交替。连着三句都不到十五字，念成口号；连着三句都过二十五字，成了文章。每段至少一句长的把场面铺开。每一段的头三个字是人或人的动作，不许是星名、宫位、「这种盘」。

**遮星测试。** 把帖里的星名和亮度全盖掉，还成立吗？还成立，就是能安在任何人身上的废话，重写。反过来也查一遍——盖掉之后一个没排过盘的人还能复述这帖在讲什么，才算落到了场面上。两头都要过。

亮度换成相反的、句子不用改，说明亮度只是装饰，也重写。

可用「什么意思」「说白了」「先搁着」。打的是俗见，不是读者本人。

**要有意思，不许一本正经宣判。** 有趣来自准：把那个场面说得太像，读者说「这是我」。不是抛梗。

能用的路：演出来别描述；夸张程度不夸张方向；突然落一句大白话收尾；反问式点破。

笑的是那种盘、那个场面，不是读者本人，也不是那位客人。凶的一刀（六亲有损、疾厄、官非）正经写，一个玩笑都不带。

## 口气（科普一条）

跟实盘那一套刻意分开。参考用户指定材料的手打科普风：把一个概念讲清楚、承认局限、例子具体、语气克制，可以有一点自嘲，不要批盘腔、不要金句腔、不要 AI 排比腔。

依据测试：把帖和原文并排放，原文里的主要论点与关键例子是否都还在、有没有多出原文没有的断语或故事。多出来的删掉；缺了原文关键层的补上（篇幅不够就在报刀里说明砍了哪一层）。

读感测试：去掉所有对仗收束句和口号后，剩下的是否仍是连贯说明。若只剩空洞对比，重写。

不许用坐馆口头禅撑科普（说白了、这种盘、先搁着、演出来、活法）。不拿凶事开刀吓人。不把「弘扬传统文化」写成每篇必喊的口号；需要时轻轻带一句即可。

## 两套共同禁止的口气

不许用：网络梗（yyds、破防、栓Q、社死这类）、谐音双关、相声腔、emoji 当笑点、编故事来垫。为了好笑改盘、加重减轻，一律禁止。

禁止：营销号（家人们、宝子、姐妹们、抓紧收藏、评论区扣1）；语气词刷屏；心灵鸡汤；恐吓包票；星名堆砌上课；谁都能套的文艺比喻；emoji 刷屏；长者腔训话；AI 感金句串。

## 匿名

不写姓名、生日、住址、联系方式、城市、学校、公司。年龄写段。能让本人对上号的组合删掉（局数＋命宫＋身份叠在一起就是）。顾客原话改写，不断义。没验的不写验。科普帖无客人可匿，仍不许虚构案例冒充实盘。

用户说「换一条」「只要拆一条」「只要科普」「标题重来」：只改被点的那截，不重开全盘。用户说「只要小红书」：才只出小红书；否则默认公众号。

## 禁止

把交付的口语全文、格局清单、四化报菜名贴出去。把待验写成应验。把没对上的改成对上。编客人、编盘。只拿先天底子那一段的料硬抽实盘帖。把外站科普原文整段粘贴。把整章术语表、干支表、历法表灌进一篇。科普帖脱离指定原文臆想发挥。科普帖套用坐馆批盘腔。

默认情况下仍写小红书。用户没要小红书却交两版。

星名当开头第一句（实盘）。压缩断单独成句。断语骨架直接贴出去。星名用简称。

开头写「今天分享一盘」或「今天科普紫微斗数」。写成教材目录或名词词典。
