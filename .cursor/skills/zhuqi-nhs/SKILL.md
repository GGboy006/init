# 紫微斗数·倪师断事加强包（薄壳）

**定位：zhuqi-zwds 的挂包，不是另一套批法。** 批法南扶北、气口平辈、有据三步、交付分支、操守、交稿验收——全部走 `zhuqi-zwds`，本文件一个字不替代。倪海厦的学问不在本地，在先生另一个「天纪/人纪全数据智能体」里；本 skill 只管三件事：**什么时候请、问题怎么写、回答怎么合。**

## 不做什么

- 不复制 zwds 规矩，不另立断法、不另定气口、不另设验收。
- 不囤倪师星情口诀当判准。硬数据（亮度、四化口诀、成格条件、安星）只认 `knowledge/iztro/`；倪师说法与库打架，听库。
- 不自己产出化解动作（阳宅改运等）。这类问题由先生去倪师智能体取回答；回话拿回来，仍过本包合盘三步（拆结构、过操守、过气口）才进交付。本包只出转换后的产出，不出风水动作本身。
- 不自动升档。默认批盘仍走 zwds 全盘解读；本包要点名才进，不许用「倪师还有更细的」吊人。

## 触发

先生说「让倪师看看」「按倪师那套断」「断具体事」「这病/这事倪师怎么看」，或精批档里要把趋势钉成**具体事相、具体应期、具体身体部位**，而 zwds 的三合＋飞化只给得到趋势、给不到「事的形状」时。

触发前先过一道：**这一问 zwds 自己答不答得动？** 星系组合＋四化＋运限能落成事的，不请。请倪师是补「应事形状」和「医命互参」的手感，不是多要一个声音。

## 请之前：问题单必须自带盘面

倪师智能体看不到这边的盘，空问只能换回讲义。每问给全：

1. 生年干支、阴阳性别、五行局、命宫身宫落哪一宫。
2. 问题落到的宫：本宫＋对宫＋三合两宫，主星与亮度（七档原名）、六煞六吉、生年四化落哪颗星。
3. 问到年份的：大限落宫（`DShian`）、流年命宫（`LNian` 下标→地支→本命宫）、流年四化；岁数换公历年份。
4. 问题本身：先生转述顾客的原话，写具体。不问「事业怎么样」，问「这步运合伙开店会不会成」这一级。
5. zwds 这一层已断出的方向，一句话带上——请倪师是在这个方向上补事相，不是让它另起炉灶。

一次最多两三问。倪师是案例教学路数，一盘一事，问具体。

**问题单写好交给先生，由先生去智能体取回答、带回来。本包不许拿训练记忆里的「倪海厦会怎么说」冒充智能体的回答**——没拿到回话，就明说「这一问等倪师回话」，不自编。

## 回答回来：合盘三步，过不了不进口语

倪师智能体给的是「倪师会怎么断」，不是交付稿。逐条过：

1. **拆结构。** 每条断拆回「哪颗星、什么亮度、坐哪宫、三方供什么、哪个四化、哪个限」。拆得回盘面的进依据，注明事相取倪师路数；拆不回的（纯口诀、「某星坐某宫主什么」、个人经验），只当参考，不进交付。
2. **过操守。** 倪师敢铁口生死、敢断病症应期。zwds 操守不减：不妄断寿元；疾病只到「哪一头弱、该去查什么科」，不替大夫下诊断；辞不辞职、分不分手、就不就医，决定权交还本人。倪师断得再猛，这几条按 zwds 收口。
3. **过气口。** 倪师是讲课口吻、师传口气、口诀体。进口语前全部按 zwds 口语规矩重写：主语是「你」、星是旁白、一句一挂、遮星测试、不报星清单、不念依据。他的猛留在依据层参考，不端给顾客。

合完仍按 zwds 两块交付：先口语后依据。

## 门派声明（用到时进交付）

三合定象为主（zwds）；倪师路数只在「应事形状、医命互参」上作加强层。只有倪师说法、三合层与库都找不着结构支撑的断，单独标出当参考，不当定论。
