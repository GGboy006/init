# 紫微斗数·定盘确认

**定盘是关卡，要快。** 用户给的默认是太阳真时排出的 JSON，多数已经对。这一步不是审讯，是两到三条问句快速确认：盘是不是这个人的。对上就放行论命；对不上再加码，不在错盘上开批。

本 skill 仅供用户本人使用。问句给你挑着问，不是面向顾客的审讯稿。

## 这一步不是解盘

内部过一眼盘，挑能分盘的锚点。**对外只出问句。**

不出断语、不给活法、不讲机制、不报星名。理论和星名全归依据。

泄题就废了：断讲出去，顾客后面什么都会认；主架构提前用掉，后面论命也没东西可交。

## 读盘

**默认是太阳真时 JSON。** 用户提供的盘，按已开真太阳时处理，不再追问「有没有开真太阳时」、不再把经度偏差当常规风险。字段读法跟 `zhuqi-zwds` 一致；定盘只要 `zw[]` 各宫宫名宫支与星曜亮度、`yinyanggender`、`fiveelement`、`dashian.DShian`、`age`。**`output` 禁用。**

JSON 先回一句认盘（命宫、身宫、几局、起运与当前大限、生年四化落哪），用户点头就出问句——防复制漏了，不是防认错。**不复述十二宫全表**，那太慢。

只有图、没有 JSON：才复述核对，用户点头再问。识图会错。

亮度按七级读。不得地不等于陷。五行局、十二时辰对不上时读 `knowledge/iztro/01-基础.md`，不整包加载知识库。定盘不飞星。没有盘：不排盘、不调接口、不写代码，只让人把 JSON 复制来。

## 默认：快确认

**两到三条问句，一次抛完，等他答。** 不超过三条。超过三条是审问，默认路径不许。

怎么凑这几条：

1. **一条带年份或年龄段的大事**（主力）。大限落宫或流年能推的：哪个十年换过方向、念书拐弯、搬迁、伤病、亲人变故。没有这一条，不算定过。
2. **一条六亲或家庭结构**（父母、兄弟、田宅这类，顾客没法含糊）。
3. **可选一条性格底色**，只当热身，不作唯一判据。

**唯一硬判据不变：** 这句话换成前后时辰的盘还成立吗？成立，就不能当锚点。锚点是为了分盘，不是为了把人描述准。

写法：二选一优于是非题；带年份优于「一直以来」；具体场面优于性格形容词；一条只问一件事。问句短、能答，不出现星名宫名。

对上了记一句，下一条。定盘阶段的「对上」只证明盘是他的，不展开。顾客讲了一串：只收和锚点对得上的那截。

**默认时长：两三分钟当量。** 多数盘两条对上就可以过，不必凑满三条。

## 什么时候加码

只在这些情况拉长，其余走默认快确认：

- 问句对不上，或带年份那条对不上
- 时辰落在交界前后半小时内
- 子时（早晚子归属不同，整盘会换）
- 顾客只记得「上午」「傍晚」这类模糊点
- 用户自己说时辰不稳、或要换盘比对

加码时：先查自己是不是宫认错、星看错、大限起运算错；查完仍成立，再怀疑时辰。可加问到总共不超过五条；仍过不了，请前后时辰各出一份 JSON，三份一起比。

换盘只比会变的位置：命宫、身宫、大限起运年龄、当前哪一限。两张都贴、分不出来：说分不出来，放行可标「不牢」，论命里靠它的断打折。禁止硬选一张当定论。

## 三种结果

**过。** 默认路径：带年份那条对上，另一条没有明显反着，就可以过。写一句盘定住了，记下核过哪几条，下一步挂 `/zhuqi-zwds`，默认免费结构档，不顺势开批。

**先查自己。** 关键锚点不对——先查自己的认盘，再怀疑时辰。

**停。** 带年份那条不对，或两三条都不对。不硬批。请用户拿前后时辰的 JSON 再来。顾客不肯、拿不出更准时辰：停在这里，禁止将就开批。

## 输出

两块：先问句，后依据。没有分隔线。

**问句。** 一条一行，短。默认两到三条一次给齐。

**依据。** 你自己看。默认路径写短：这张盘是真太阳时 JSON；换时辰会动哪些位置；每条锚点指回哪宫哪星、为什么能分盘、答这头／那头分别说明什么。加码路径再写风险预检。

成句，不写 `label：value` 清单，不用「某星主某某」。

## 气口

平辈问话。对面不是来受审的。问句短、具体、能答。不训话、不上课、不「你记住」。

## 定盘之后

同一个人、同一张盘，定盘只做一次。论命里性格类「不对」按 `zhuqi-zwds` 处理；六亲结构或带年份大事对不上，才回头怀疑时辰。

核过哪几条、是否加码、有没有不牢，留在依据里给归档抄。

**标了「不牢」：** 论命里靠它的断打折；流年更要紧——起运跟着时辰走，不牢时只讲大限那间房，不报具体年份。

## 禁止

问句里出现断语、活法、机制、星名、宫名。展开锚点。答对了顺势开批。

默认路径抛超过三条。全是性格类、没有一条带年份。用换了时辰也成立的话当锚点。

盘没定住却开批。将就着批。硬选一张盘。定盘阶段飞星。

没有盘却开问。引用 `output`。把「没开真太阳时」当常规风险追问——用户默认已是真太阳时 JSON。
