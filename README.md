## 解盘三份的共用规约

只对本命、流年、阳宅这三份成立。归档和发帖不走这一套。

**批法学倪海厦，气口不学。** 他堂上是长者训话，对面坐的是小红书上找来的年轻人，平辈讲话。不讲星卦来历、不引门派源流、不举别人的例子、不说「大家看」，也不摆长者架子、不「你记住」压人、不刷宝子腔。

**先人话，后点星。** 每一断先说场合、动作、别人看见什么，星名跟在后面当锚。星名开头就成了黑话，第一句就把人挡在门外。断语骨架（巨门陷、话讲拧）归依据那半截。

**要有意思，不许一本正经宣判。** 有趣来自准，不来自段子——好笑的是那个场面被说得太像，他自己认出来了。一段一两处，笑完落回怎么活。凶的段（煞重、六亲有损、疾厄、生死）正经讲，一个玩笑都不带。禁网络梗、谐音双关、相声腔、emoji，禁拿顾客短板当笑柄，禁为了好笑改盘。

**交稿验收**：能直接念不改字；念的时候不用回头看依据；把星名全去掉，一个没排过盘的人能复述发生了什么。压缩断（撑不住、不亮、漏、走暗）不许单独成句。

**默认分段**，一段念不超过一分半，用户说「接着」出下一段。长度跟着这一宫的星走，不按字数；星少就短，短了不补，不许掺水。

**输出两截**，中间隔一行 `———— 以下不念 ————`：上截是可直接念的讲稿，纯口语无 markdown；下截写盘面依据和为什么这么断，用户自己看，不念。

**断要同看，讲按段交付。** 开口前先定主轴，后面每段挂回主轴。盘面有据在先，不为口气牺牲精准；指不回图上的断语一律删。

**合盘总收不默认出**，用户说「总收」「合起来讲」才出。

## 攒毛病

批完发现的毛病先记在 `.cursor/skills/zhuqi-zwds/PENDING.md`，攒一批再合进 `SKILL.md`，合完清掉。

每条记三样：哪次盘、犯了什么（skill 里已有哪条没挡住）、待写入的判据。「犯了什么」这一栏最有用，它分得清是新问题还是旧规则太弱。

不要把当次批词当范文贴进 SKILL。
