## 单一真源

**`zhuqi-zwds/SKILL.md` 是格式、气口、验收的唯一真源。** 流年和阳宅不复述这几节，只在开头要求先读那一份的四节（输出、有据、气口、交稿验收），然后各写自己独有的东西——流年写时间层怎么叠，阳宅写卦位怎么变成人事。

这么分是为了不双份维护。同一条规则写在两个文件里，改了一头忘了另一头，就会读到两条互相矛盾的规则，还分不出哪条新。**要改格式或气口，只改 `zhuqi-zwds`。**

定盘、归档、发帖各有自己的活，不套这一套：定盘只出问句不出断语；归档只记事实；发帖的读者是滑动的人，不是坐对面的顾客。

## 三份解盘的共用底线

只对本命、流年、阳宅成立。这里是提要，细则在 `zhuqi-zwds`。

**平辈解盘。** 对面是个来问自己命的人，不是来听课也不是来受教。你比他懂盘，不比他大一辈。有判断、有褒贬、该说重就说重，但不摆长者架子、不训话、不「你记住」压人、不刷宝子腔。不讲星卦来历、不引门派源流、不举别人的例子、不说「大家看」。

**批法南扶北。** 前两档三合定象，深度精批加飞化追事。四化口诀用通行本；跟别家口诀不同就声明，两套不许混着断还不说哪一层是主。

**每块两样，先口语后依据。** 没有分隔线。口语给顾客听，用户映照着讲、自己改口，不出逐字讲稿；依据给用户学思路，顾客问「为啥」时当场能接。分量按盘走，不限句数字数。

**口语第一句是日子。** 主语「你」，谁、在哪、干什么。第一句是星名、宫名、卦名、方位的，重写。

**遮星测试是最硬的自检。** 把口语里的星名（阳宅是卦名方位）和亮度全盖掉，段子还成立的，就是能安在任何人身上的废话，重写。亮度换成相反的还讲同一句话，说明亮度只是装饰。交稿前跑一遍。

**不许两头堵。** 正反都覆盖、好也行坏也行，等于没断。断只走一个方向，走错了才有得改。

**一象一处。** 断哪个领域，先看管那个领域的宫或卦。指不回禄或财，不许讲怎么赚钱。

**盘面有据在先，不为口气牺牲精准。** 指不回图面、也给不出推导的，删。宁可少讲一句，不可讲错一颗星、一个宫、一个宫干。

**默认分段。** 只交付当前段，段末不追问要不要继续。用户说「接着」出下一段。合盘总收不默认出。

**带年份的断才可核。** 岁数一律换成公历年份。已经过去的年份优先拿来对账——这是唯一能让批法长进的东西。

**示例都是别的盘。** 各份 SKILL 里的对照表和示例只定形状和口气，句子不许搬进交付。

## 攒毛病

批完发现的毛病先记在 `.cursor/skills/zhuqi-zwds/PENDING.md`，攒一批再合进 `SKILL.md`，合完清掉。

每条记三样：哪次盘、犯了什么（skill 里已有哪条没挡住）、待写入的判据。「犯了什么」这一栏最有用，它分得清是新问题还是旧规则太弱。

**拿弱模型的输出来查 skill 特别有效。** 它会精确地暴露哪句话可以被字面理解成错的——示范句跟条文顶牛、示例用了当次那张盘、规则藏在长句尾部被跳过，这几类都是这么查出来的。

不要把当次批词当范文贴进 SKILL。

## 分工

丢命盘先走定盘。定盘过了才进本命，默认只出免费结构档，用户说升档才往下走。

优先要排盘接口的 JSON，没有才认图；只有图的先复述核对，用户点头才开批。接口的 `output` 字段是套话，禁用。

问今年、这两年、大限，走流年——须先定盘、且本命批过。丢户型、谁住哪、厨厕门、搬家改运，走阳宅。

解完要存档走归档，存进 `cases/` 并更新 `cases/验证账.md`。要发小红书或公众号走发帖，从这盘抽一刀，不搬整盘；免费结构档的料抽不出帖。

紫微和阳宅可以连用：先看见管道，再改位置。
