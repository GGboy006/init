## 单一真源

**`zhuqi-zwds/SKILL.md` 是流程、四层交付、气口、验收、时间层读法的唯一真源。** `zhuqi-nhs` 是薄壳挂包，不复述这些，只管什么时候请倪师、问题单怎么写、回答怎么合；合完仍按 zwds 四层交付。

这么分是为了不双份维护。同一条规则写在两个文件里，改了一头忘了另一头，就会读到两条互相矛盾的规则，还分不出哪条新。**要改流程、格式、气口或大限流年读法，只改 `zhuqi-zwds`。**

定盘、归档、发帖各有自己的活，不套这一套：定盘只出问句不出断语；归档只记事实；发帖的读者是滑动的人，不是坐对面的顾客。

## 解盘的共用底线

细则在 `zhuqi-zwds`，这里是提要。

**平辈解盘。** 对面是个来问自己命的人，不是来听课也不是来受教。你比他懂盘，不比他大一辈。有判断、有褒贬、该说重就说重，但不摆长者架子、不训话、不「你记住」压人、不刷宝子腔。不讲星卦来历、不引门派源流、不举别人的例子、不说「大家看」。

**批法南扶北。** 三合定象为本，飞化追事为用（精批）。四化口诀用通行本；跟别家口诀不同就声明，两套不许混着断还不说哪一层是主。

**每块四层交付。** 【你现在做什么】动作话术、【跟客人说】短版长版各一（短版一两句可原样出口，长版展开指盘）、【解法】盘上给了有据预警时把抽象风险翻成一句能对上号的原话＋一个能做的动作（没预警不硬塞，只当预案不当断语，不缝星曜对照表）、【你的底气】断法思路链（盘面→往哪断→嘴上可落成哪类话），不逐句对译、不写星义字典。分量按盘走。

**口语第一句是日子。** 主语「你」，谁、在哪、干什么。第一句是星名、宫名、方位的，重写。

**遮星测试是最硬的自检。** 把口语里的星名和亮度全盖掉，段子还成立的，就是能安在任何人身上的废话，重写。亮度换成相反的还讲同一句话，说明亮度只是装饰。交稿前跑一遍。

**不许两头堵。** 正反都覆盖、好也行坏也行，等于没断。断只走一个方向，走错了才有得改。

**一象一处。** 断哪个领域，先看管那个领域的宫。指不回禄或财，不许讲怎么赚钱。

**盘面有据在先，不为口气牺牲精准。** 指不回图面、也给不出推导的，删。宁可少讲一句，不可讲错一颗星、一个宫、一个宫干。

**默认分段。** 只交付当前段，段末不追问要不要继续。用户说「接着」出下一段。合盘总收不默认出。

**带年份的断才可核。** 岁数一律换成公历年份。大限／流年读 `dashian.DShian`／`LNian`，流年十二宫逆地支。已经过去的年份优先拿来对账。

**示例都是别的盘。** 各份 SKILL 里的对照表和示例只定形状和口气，句子不许搬进交付。

## 攒毛病

批完发现的毛病先记在 `.cursor/skills/zhuqi-zwds/PENDING.md`，攒一批再合进 `SKILL.md`，合完清掉。

每条记三样：哪次盘、犯了什么（skill 里已有哪条没挡住）、待写入的判据。「犯了什么」这一栏最有用，它分得清是新问题还是旧规则太弱。

**拿弱模型的输出来查 skill 特别有效。** 它会精确地暴露哪句话可以被字面理解成错的——示范句跟条文顶牛、示例用了当次那张盘、规则藏在长句尾部被跳过，这几类都是这么查出来的。

不要把当次批词当范文贴进 SKILL。

## 分工

丢命盘先走定盘。定盘过了进 zwds 六步：认盘 → 开场三问（时辰、现状、边界）→ 心里过盘 → 定调 → 按档交付（专项答 30 分钟／全盘批 60–90 分钟，边界由客人定，AI 不替选）→ 收口归档。说「精批」「飞化」才进精批。

优先要排盘接口的 JSON，没有才认图；只有图的先复述核对，用户点头才开批。接口的 `output` 字段是套话，禁用。

年份是全盘批的标配、专项答问到就同段叠；大限只读 `DShian`、流年只读 `LNian`，岁数换公历。三合钉不死的事相病相、阳宅化解，走 `/zhuqi-nhs` 出问题单，先生去倪师智能体取回答。

解完要存档走归档，存进 `cases/` 并更新 `cases/验证账.md`（气口栏选填）。要发小红书或公众号走发帖，从这盘抽一刀，不搬整盘；本命段未到场面的料抽不出帖。

## 本地知识库

`knowledge/iztro/` 是 iztro.com/learn/ 的知识库（markdown + `kb.csv`），给模型核对数据和推理用，不是速查表。走 `/zhuqi-zwds` 时按用到的读对应篇，拿不准优先读库，也可以完全按库推理。不要开口前先读一张总表。盘认图／JSON，断法气口认 skill，模型只负责落到这张盘，不许跟训练记忆平均。两边打架听 skill。用法细则在 skill「知识库」节。

紫微和倪师路数可以连用：zwds 定方向趋势，`zhuqi-nhs` 补事相病相的形状。
