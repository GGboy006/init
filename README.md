## 解盘三份的共用规约

只对本命、流年、阳宅这三份成立。归档和发帖不走这一套。

**面对面给顾客解盘的口气，不是上课口气**：不讲星卦来历、不引门派源流、不举别人的例子、不说「大家看」。

**默认分段**，一段念不超过一分半，用户说「接着」出下一段。长度跟着这一宫的星走，不按字数；星少就短，短了不补，不许掺水。

**输出两截**，中间隔一行 `———— 以下不念 ————`：上截是可直接念的讲稿，纯口语无 markdown；下截写盘面依据和为什么这么断，用户自己看，不念。

**断要同看，讲按段交付。** 开口前先定主轴，后面每段挂回主轴。盘面有据在先，不为口气牺牲精准；指不回图上的断语一律删。

**合盘总收不默认出**，用户说「总收」「合起来讲」才出。

## 攒毛病

批完发现的毛病先记在 `.cursor/skills/nihaixia-zwds/PENDING.md`，攒一批再合进 `SKILL.md`，合完清掉。

每条记三样：哪次盘、犯了什么（skill 里已有哪条没挡住）、待写入的判据。「犯了什么」这一栏最有用，它分得清是新问题还是旧规则太弱。

不要把当次批词当范文贴进 SKILL。

## 分工

丢命盘截图走本命：只认图，不排盘、不调接口、不写代码。没有图就让人把盘截来。

问今年、这两年、大限，走流年。丢户型、谁住哪、厨厕门、搬家改运，走阳宅。

解完要存档走归档，存进 `cases/` 并更新 `cases/验证账.md`。要发小红书或公众号走发帖，从这盘抽一刀，不搬整盘。

紫微和阳宅可以连用：先看见管道，再改位置。
