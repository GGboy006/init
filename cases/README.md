# 实盘案例

一盘一文件。写给以后的自己看，不是给顾客看。

命名：`日期-性别局数-命宫主星.md`，例 `2026-08-29-阳女木三局-命巨门在戌.md`。同一天两盘加 `-2`。

匿名。不存姓名、生日、住址、联系方式。盘面结构和顾客原话可以留，能认出人的删掉。

三样东西分开放，别混：

| 东西 | 去处 |
| --- | --- |
| 批法规则、口气、禁止 | `.cursor/skills/*/SKILL.md` |
| 批完发现的毛病，攒着待合 | `.cursor/skills/zhuqi-zwds/PENDING.md` |
| 这一盘断了什么、顾客怎么应 | `cases/` 下的案例文件 |
| 跨盘反复应验或反复落空的断法 | `cases/验证账.md` |

当次批词只进案例，不进 SKILL.md。一条断法要进验证账，得在两张以上的盘上被顾客的实事核过，而且要带年份或可核的事实——性格类的断进不了验证账，它永远说得通，也永远证不伪。

案例里记档位和定盘结果。定盘没过的盘不该有案例；有，说明流程被跳了，要在案例里标出来。
