# 紫微斗数四化

来源：iztro.com/learn/mutagen。

## 四化总论

四化星只有四颗，但构成紫微斗数的动态，把平面星盘变立体。星曜组合是环境，四化是念头。四化不能独立存在，只能依附其他星曜，改变相关星曜的性质。

同一颗星在不同四化下感受不同：可能更活跃或更沉默、更强硬或更软弱，这本身不是好坏标准。

四化分两类：

- **运限四化**：本命、大限、流年、流月、流日、流时四化，按所在运限天干产生。本命与大限四化因人而异，其余运限四化同一时间点人人相同。
- **宫位四化**：每个宫位的宫干产生的四化。

## 四化各自意象

### 化禄（土，开心、忙碌、增加、包容、多）

「增加」的力量，相当于某宫位某星上有额外收获。人对与生俱来的好感受不明显，觉得理所当然。是「增幅器」，先懂主星本质才能懂禄增加什么：破军化禄＝增加消耗；天同化禄＝增福气享受（也会更不思进取）。增加的东西通常让人开心。

### 化权（木，占有、责任、执行、权利、大）

「掌控」的力量，执行与权利。掌控所在宫位：官禄宫化权＝想事业有建树、掌控自己负责的事。代表责任感、增自信。化权不一定是升职，但手上事情会变多。增压迫感，使棱角明显。化权到六亲宫＝权利的转移，想控制管理该六亲易争执。

### 化科（水，随和、面子、贵人、名声、适中）

负面能量最少的星。所在宫位是当事人「最有面子」的宫位，易显摆。身心疲累时提供情绪价值的宫位（贵人星）。展示出来会有「名气」。科落六亲宫＝该宫位人较有涵养；落六事宫＝不用太费力就舒服的宫位。平顺不波折，但缺企图心。

### 化忌（水，纠结、关注、在乎、麻烦、少）

忌字拆开上己下心，代表自己的内心。感受最强烈的一颗（关心则乱）。所在宫位＝当事人最关心最在乎的宫位。化忌是执念所在，不能以单纯好坏定论，是人动力的来源（觉得缺才想去补）。

- 忌落六亲宫：这个人/关系你很在意，分歧时内心伤害大。
- 忌落六事宫：对这宫有执念、觉得有缺憾（生年忌在财帛＝觉得财少、机会少，会非常努力赚钱，易闷声发大财）。

## 四化同宫的组合

| 组合 | 含义 |
| --- | --- |
| 禄+忌 | 开心来源但觉不足，纠结，食之无味弃之可惜 |
| 禄+权 | 开心来源且想掌控，控制欲强，想在该宫取得成就 |
| 禄+科 | 开心又有面子，喜展示，对该宫相关事自信 |
| 权+忌 | 想掌控又觉不足，过高要求易生矛盾 |
| 权+科 | 想掌控又有面子，重该宫名声 |
| 科+忌 | 该有面子又有不足，为该宫默默付出 |

## 飞星系统

飞星＝A 宫的宫干让 B 宫某星曜产生四化，叫 A 宫「飞 x 星」到 B 宫，或「化 x」到 B 宫。若 B 宫星曜化忌，会冲到 B 宫的对宫 C 宫，叫 A 宫化忌冲 C 宫。

- **A 化禄入 B**：A 让 B 能量增加，A「喜欢」B，B 是 A 快乐的来源。
- **A 化权入 B**：A 把权力交 B，希望 B 承担更多责任，A「依赖」B；B 是事宫＝A 想掌控 B、为 B 做得更多。
- **A 化科入 B**：A 认为 B 是面子来源，较展示 B 特质，B 能帮 A 排忧解难。
- **A 化忌入 B**：A 感觉 B 是烦恼来源，A「牵挂」B；忌入冲 B 的对宫，C 宫才是让 A 烦恼的源头。
- **A 宫自化**：自我感觉，不一定真有此现象，较难克服。自化禄＝觉得能量够了不珍惜；自化权＝觉得该承担/该获取更多，付出更多；自化科＝自恋；自化忌＝自寻烦恼。

> 宫干飞化目标主体是命主本人，一切透过命主看待飞化结果。
