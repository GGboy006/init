本目录把 iztro.com/learn/ **全文**当作知识库，给模型核对数据和推理用。不是摘录，不是速查表。拿不准优先读这里，也可以完全按这里的原文推理。气口、取象、档位只认 `zhuqi-zwds`。

各篇只去掉站点组件（Donate、script、Badge），正文未删改。古籍三卷＋问答一并收入，赋文可核出处，不当判准。

## 结构

- `01`–`12` 的 markdown：按原站点一篇一文件（古籍分卷另存）。
- `index.csv`：篇目索引。
- `kb.csv`：按小节切成行，检索用（`id,category,heading,content,source_url`）。

强制步骤写在 `zhuqi-zwds` 的「知识库」节。解盘不是把这目录全塞进上下文。
