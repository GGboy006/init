## 怎么用（解盘）

强制步骤写在 `zhuqi-zwds` 的「知识库」节，本页只给对照。解盘不是「把这目录全塞进上下文」。

**每次解盘：**

1. 走 `/zhuqi-zwds`（或说「看盘」「批这张」）。模型必须先 Read `查表速查.md`。
2. 你要钉死当次，第一句自己 `@knowledge/iztro/查表速查.md`。
3. 用到哪一类再 `@` 或让模型补读哪一篇，一次一篇。

| 你要核 | `@` 哪个 |
| --- | --- |
| 亮度、四化口诀、合冲、五行局、五虎遁、易错格 | `查表速查.md` |
| 某格成不成 | `09-格局.md` |
| 宫干、斗君、安星口诀 | `11-安星诀.md` |
| 飞化怎么读 | `08-四化.md` |
| 某颗星本义拿不准 | `05-主星.md`／`06-辅星.md`／`07-杂耀神煞.md` |
| 古籍某赋在哪 | `12-古籍.md`（只给链接） |

**不要** `@` 整个 `knowledge/iztro/` 文件夹，也不要把 01–03、12 当判准。

合的顺序（不是「库＋模型自己的＝更真」）：硬表只认本目录；盘只认图／JSON；怎么断怎么说只认 `zhuqi-zwds`；模型只负责把表落到这张盘上。记忆跟表不一致，丢记忆。查过仍对不上，写拿不准，不许补洞。两边打架听 skill。
